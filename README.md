# CODE TECH Portfolio

Premium digital agency website built with React, Vite, TypeScript, Tailwind CSS, and Framer Motion.

## Features

- Responsive multi-page portfolio website
- Dark and light theme toggle
- Premium agency branding and marketing layout
- Services, products, about, and contact sections
- Contact form UI with validation

## Tech Stack

- React 19
- Vite
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Getting Started

1. Install dependencies:
   npm install
2. Run the development server:
   npm run dev
3. Build for production:
   npm run build

## Project Structure

- src/ - app source files
- public/ - static assets and logo files
- logos/ - brand icon and logo assets
